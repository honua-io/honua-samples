Switching from ArcGIS

Every ArcGIS job has a Honua home. Your tools keep working while you move.

Honua covers the server, the portal and hub, the app builders, administration and AI assistance. During the move, ArcGIS clients and the systems that read your services point at Honua's GeoServices REST and OGC endpoints, so nothing breaks on the way.

Migration path

Honua stands up beside ArcGIS. Each step is reversible until the last one, and nothing has to move on a single weekend.

1
Weeks 1–2

Stand up Honua beside ArcGIS

Install Honua Server in the county data center or your cloud tenant, connected to PostGIS.

  • Single sign-on with county accounts
  • Roles mirror existing groups
2
Weeks 2–4

Publish the same data

Import from file geodatabases, shapefiles or existing feature services. Coordinate systems are detected and kept.

  • Same layer names and fields
  • Styles carried across
3
Weeks 4–8

Point existing clients at Honua

Change the service URL in each desktop project, web map, permitting lookup and EOC board. Test each one in the pilot.

  • GeoServices REST and OGC side by side
  • Field apps sync against Honua
4
Months 2–4

Rebuild apps in Studio

Recreate public apps, dashboards and the open data hub in Studio and Catalog, then release them on the same addresses.

  • Draft, version, release
  • Agents turned on with approvals
5
At renewal

Retire what nobody opens

Console activity shows which old services and apps still get traffic. Retire them when the count reaches zero.

  • Fewer licences to renew
  • One platform to patch and audit

Is Honua certified by Esri?
No. Honua implements the published GeoServices REST specification and OGC standards. Compatibility is tested client by client in your pilot.
What does it cost to switch?
The data stays in PostGIS and does not need re-entry. The work is a URL change per client and rebuilding web apps in Studio. Licences you no longer use are dropped at renewal.
Is Honua open source?
Honua is source-available under the Fair Core licence, built on open standards and self-hostable.
